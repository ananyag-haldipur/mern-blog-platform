# Blog Platform with Comments

## Features
- User registration and login
- JWT authentication
- Create, update and delete posts
- Comment system
- Search posts
- Category filtering

## Tech Stack

Frontend:
- React.js
- React Router
- Axios

Backend:
- Node.js
- Express.js

Database:
- MongoDB Atlas

## Run Project

Frontend:
npm install
npm run dev

Backend:
npm install
npm run dev
